# Object-Oriented Programming in C++

Console applications exploring classes, inheritance, polymorphism, exception handling, graph management, circuits, and data models.

Coursework by **Ali Amiri**, Sharif University of Technology. Semester 6 — Object-Oriented Programming.

## Selected applications

| Directory | Application |
|---|---|
| `hw3/q1` | Airplane and runway model |
| `hw3/q2` | Access-point command model |
| `hw3/q3` | Users, planes, and flight management |
| `hw4/q1` | Large-number arithmetic |
| `hw5/q1` | FIFO abstraction |
| `hw6/q1` | Food inheritance hierarchy |
| `hw6/q2` | Circuit components and analysis |
| `hw6/q3` | University people, courses, and grades |
| `hw7/q1` | Clinic management and exceptions |
| `hw7/q2` | Graph manager |
| `hw8/q1` | Typed datasets and operations |
| `hw8/q2` | Leitner flashcard system |

Each directory has an independent entry point. For example:

```bash
g++ -std=c++17 -O2 hw6/q2/main.cpp -o circuit
./circuit
```

Command syntax is defined by each program's input loop. Drafts, empty IDE classes, hello-world examples, and an SDL exercise with unresolved asset/dependency requirements are excluded.
